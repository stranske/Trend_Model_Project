1. 📈 Monte Carlo: emit nav_paths (NAV path matrix) in results metadata
Labels: montecarlo, visualization, streamlit, enhancement

Why
The Streamlit Monte Carlo page extracts a `nav_paths` DataFrame and passes it into `mc_plots.render_fan_chart`, but today that frame is often empty, which blocks fan charts and prevents reusing PAEM’s Plotly viz stack.

Scope
- Extend `trend_analysis.monte_carlo.runner.MonteCarloRunner` to compute and attach NAV paths for each simulated path (opt-in).
- Store outputs on `MonteCarloResults.metadata` under a stable key (`nav_paths`), and define fold-aware handling.
- Update `streamlit_app/pages/monte_carlo.py` to select the correct NAV paths for the current fold selection.
- Ensure schema is compatible with TMP’s existing `_nav_long_frame` logic (supports MultiIndex with `path` / `asset`).

Non-goals
- Do not persist every intermediate series; only what’s needed for visualization and export.
- Do not redesign the Monte Carlo engine or strategy evaluation contract.

Tasks
- Decide and document the canonical `nav_paths` schema:
  - Index: datetime-like (period end dates)
  - Values: float NAV (start at 1.0)
  - Columns: plain path ids OR MultiIndex that includes levels named `path` and `asset` with `asset="NAV"`.
- Implement NAV extraction in `MonteCarloRunner.run()`:
  - After each path simulation, extract a single portfolio series (prefer existing helpers if present).
  - Build per-path NAV and add to an accumulating DataFrame.
  - For fold runs: store per-fold NAV paths (e.g., metadata["nav_paths_by_fold"] = {fold_id: df}).
- Update Streamlit:
  - Extend `_extract_nav_paths` (or wrap it) to accept fold selection and choose `nav_paths_by_fold[fold_id]` when present.
- Export support:
  - Extend `trend_analysis.monte_carlo.results.export_results()` (or the exporter used by the page) to write `nav_paths.parquet` when present.
- Tests:
  - Unit test: deterministic per-path series → nav_paths exists, non-empty, correct shape.
  - Fold test: fold selection returns the correct per-fold nav_paths.

Acceptance criteria
- Running the Streamlit Monte Carlo page yields a non-empty fan chart (no empty-frame fallback).
- `results.metadata["nav_paths"]` exists for non-fold runs.
- For fold runs, selecting Fold N shows the correct fold’s NAV paths.

Implementation notes
- Streamlit calls `mc_plots.render_fan_chart(nav_paths)` and `mc_plots._nav_long_frame` supports MultiIndex columns with `path` and `asset` levels.
